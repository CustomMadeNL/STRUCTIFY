# STRUCTIFY — Launch Checklist

A single, ordered checklist to take a product from "content ready" to "live and
selling." Do it fully for **P-001** first, then repeat for **P-002**.

## Phase 1 — Finalize delivery (per product)

- [ ] Confirm all module Google Sheets are final and set to **"Anyone with the link — Viewer"**
- [ ] Replace every `PASTE LINK HERE` placeholder in the delivery guide with the real Sheet links
- [ ] Add the Start Here link, main product link and support contact (info@custommade.agency)
- [ ] Export the delivery guide as a clean PDF
- [ ] Open the PDF as a buyer would and click every link — all must work

## Phase 2 — Visuals (per product)

- [ ] Cover image (product name + outcome, readable in 3s)
- [ ] Included-modules image
- [ ] Dashboard / command-center preview
- [ ] Module/agent preview screenshot
- [ ] "How it works" image
- [ ] QA: black/white/off-white only, premium feel, readable on mobile

## Phase 3 — Publish on Payhip (fastest first)

- [ ] Create the product using [`../products/<product>/listing-payhip.md`](../products)
- [ ] Set price (launch price for first release)
- [ ] Upload the finalized delivery PDF as the downloadable file
- [ ] Add cover + preview images
- [ ] Publish and copy the live URL into `docs/STATUS.md`

## Phase 4 — Publish on Etsy

- [ ] Create the listing using [`../products/<product>/listing-etsy.md`](../products)
- [ ] Paste title, description and all 13 tags
- [ ] Set price and mark as digital download
- [ ] Upload images + delivery file (or delivery PDF that links out)
- [ ] Publish and copy the live URL into `docs/STATUS.md`

## Phase 5 — Test & verify

- [ ] Run a real test purchase end-to-end (Payhip and Etsy)
- [ ] Confirm the delivery email + download works for the buyer
- [ ] Confirm "Make a copy" works on every linked Sheet
- [ ] Fix anything broken, then mark the product **LIVE** in `docs/STATUS.md`

## Phase 6 — Traffic

- [ ] Create Pinterest pins (see [`PINTEREST.md`](PINTEREST.md))
- [ ] Schedule/publish pins linking to the listing
- [ ] Log the first sales in the revenue tracker

## Definition of "LIVE"

A product is LIVE when: the listing is published, a test purchase succeeded, the
buyer can access every file, and the URL is recorded in `docs/STATUS.md`.
