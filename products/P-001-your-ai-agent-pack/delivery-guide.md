## Page 4 — How to use this product

Always work inside **your own copy**. This protects the original files and keeps
your version private.

1. Open the file link from Page 5.
2. Go to **File → Make a copy**.
3. Save the copy in your own Google Drive.
4. Edit only your copied version.

**Do not skip this.** Making a copy prevents accidental edits to the original
STRUCTIFY files.

**Recommended use**
- Use the system weekly, not once.
- Start with the agent that solves your biggest bottleneck.
- Keep your outputs in one central folder.
- Add new agents only after the first workflow works.
