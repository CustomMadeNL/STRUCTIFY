## Customer flow

1. Open **Start Here** — understand how to use the pack.
2. Choose the AI goal (planning / email / content / research / projects / automation).
3. Open **AI Command Center** — set up the dashboard.
4. Pick the first agent (start with one, not all).
5. Use the prompt library for immediate output.
6. Run a weekly review; add the next agent only when the first workflow works.
