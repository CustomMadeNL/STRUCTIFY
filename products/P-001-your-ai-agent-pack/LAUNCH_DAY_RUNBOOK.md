# P-001 — Launch-Day Runbook

**Goal:** get *Your AI Agent Pack* live and taking orders **today**.
**Order of play:** finalize files → Payhip (fastest) → Etsy → traffic.
**Estimated time:** ~2–3 hours if mockups are ready; ~4 with mockups.

Tick each box as you go. Copy blocks are already written in this repo — this
runbook just tells you which file to grab and where to paste it.

---

## Step 0 — Before you start (5 min)

- [ ] Open these repo files in tabs, you'll paste from them:
  - `products/P-001-your-ai-agent-pack/delivery-guide.md`
  - `products/P-001-your-ai-agent-pack/listing-payhip.md`
  - `products/P-001-your-ai-agent-pack/listing-etsy.md`
  - `launch/POLICIES_AND_FAQ.md`
- [ ] Have your Payhip and Etsy seller accounts logged in.

---

## Step 1 — Finalize the product files (20–30 min)

- [ ] Open each of the 8 module Google Sheets (Start Here, AI Command Center, and the 6 agents).
- [ ] For each: **Share → General access → Anyone with the link → Viewer**. Copy the link.
- [ ] Open `delivery-guide.md`, go to **Page 5 – Access your files**, and replace every `[PASTE LINK]` with the matching real link.
- [ ] Read the guide top to bottom once. Fix any typo or wrong name.
- [ ] Export the guide to **PDF** (from Google Docs/Canva: File → Download → PDF), named `Your-AI-Agent-Pack-Delivery-Guide.pdf`.
- [ ] Click **every link** in the exported PDF as if you were a buyer. All 8 must open and allow "Make a copy."

✅ *Done when:* one clean PDF exists and every link works.

---

## Step 2 — Mockups (skip if already done) (30–45 min)

Minimum viable set (5 images), per `../../launch/PINTEREST.md` and the brand rules
(black / white / off-white, name + outcome readable in 3s):

- [ ] Cover — "Your AI Agent Pack / Build your personal team of AI assistants"
- [ ] Included modules (the 8-item list)
- [ ] AI Command Center preview (screenshot)
- [ ] One agent preview (screenshot)
- [ ] "How it works" (the 5-step quick start)

✅ *Done when:* 5 PNGs exported, readable on mobile.

---

## Step 3 — Publish on Payhip (30 min) — do this first

- [ ] **Add new product → Digital product.**
- [ ] Name: from `listing-payhip.md` → *Product name*.
- [ ] Upload file: attach `Your-AI-Agent-Pack-Delivery-Guide.pdf` as the deliverable.
- [ ] Description: paste *Full description* from `listing-payhip.md`.
- [ ] Add the FAQ block from `launch/POLICIES_AND_FAQ.md` (section 3) to the bottom of the description.
- [ ] Price: set **€29** (launch price). Optionally set a "compare at" of €49.
- [ ] Images: upload the 5 mockups; set the cover as the main image.
- [ ] Store policy / refund: paste the refund + license short lines (sections 1–2).
- [ ] **Publish.** Copy the live URL.

✅ *Done when:* the Payhip product page is live and the URL is saved.

---

## Step 4 — Test purchase on Payhip (10 min)

- [ ] Create a 100% discount code (e.g. `TESTONLY`) or use Payhip's preview/test order.
- [ ] Buy the product as a customer.
- [ ] Confirm: order email arrives → download works → PDF opens → a linked Sheet opens and "Make a copy" works.
- [ ] Delete/disable the test code afterwards.

✅ *Done when:* the full buyer flow works end to end.

---

## Step 5 — Publish on Etsy (30–40 min)

- [ ] **Shop Manager → Listings → Add a listing → Digital.**
- [ ] Title: paste from `listing-etsy.md` → *Title*.
- [ ] Photos: upload the 5 mockups (cover first).
- [ ] About: Made by you / A finished product / When made: 2026.
- [ ] Category: Paper & Party Supplies → Paper → (or a Digital Prints / Templates path); Type = Digital download.
- [ ] Price: **€49** (or run an Etsy sale to show the €29 launch price).
- [ ] Quantity: high (e.g. 999). Digital file: upload the delivery-guide PDF.
- [ ] Description: paste *Description* from `listing-etsy.md`, then append the FAQ block (POLICIES_AND_FAQ section 3).
- [ ] Tags: paste all 13 from `listing-etsy.md`.
- [ ] Shop policies: make sure the digital refund + license policy (sections 1–2) is set in Shop → Policies.
- [ ] **Publish.** Copy the live URL.

✅ *Done when:* the Etsy listing is live and the URL is saved.

---

## Step 6 — Record it (5 min)

- [ ] Update `docs/STATUS.md`: mark P-001 **LIVE**, add both URLs, bump "Products live" / "Listings live" to reflect reality.
- [ ] Add the first sale rows to your revenue tracker as they come in.

---

## Step 7 — First traffic (optional, same day) (20 min)

- [ ] Create 2–3 Pinterest pins from `../../launch/PINTEREST.md` (P-001 titles).
- [ ] Link each pin to the Payhip or Etsy listing.
- [ ] Publish / schedule.

---

## Done = "LIVE"

P-001 is LIVE when: the listing is published on at least Payhip, a test purchase
succeeded, the buyer can open every file, and the URL is recorded in
`docs/STATUS.md`. Then repeat this runbook for **P-002 – Business Operating System**.
