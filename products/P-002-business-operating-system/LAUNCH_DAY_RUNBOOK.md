# P-002 — Launch-Day Runbook

**Goal:** get the *Business Operating System* live and taking orders.
**Order of play:** finalize files → Payhip (fastest) → Etsy → traffic.
**Estimated time:** ~2–3 hours if mockups are ready; ~4 with mockups.

Run this **after P-001 is live** (see `../P-001-your-ai-agent-pack/LAUNCH_DAY_RUNBOOK.md`).
Copy blocks are already written in this repo — this runbook just tells you which
file to grab and where to paste it.

---

## Step 0 — Before you start (5 min)

- [ ] Open these repo files in tabs, you'll paste from them:
  - `products/P-002-business-operating-system/delivery-guide.md`
  - `products/P-002-business-operating-system/listing-payhip.md`
  - `products/P-002-business-operating-system/listing-etsy.md`
  - `launch/POLICIES_AND_FAQ.md`
- [ ] Have your Payhip and Etsy seller accounts logged in.

---

## Step 1 — Finalize the product files (25–35 min)

- [ ] Open each of the 9 module Google Sheets (Start Here, Positioning, Offer Design, Client Avatar, Content, Sales, CRM, Pipeline, KPI Dashboard).
- [ ] For each: **Share → General access → Anyone with the link → Viewer**. Copy the link.
- [ ] Open `delivery-guide.md`, go to **Page 5 – Access your files**, and replace every `[PASTE LINK]` with the matching real link. **Mind the order** (0 Start Here → 8 KPI Dashboard).
- [ ] Read the guide top to bottom once. Fix any typo or wrong name.
- [ ] Export the guide to **PDF**, named `Business-Operating-System-Delivery-Guide.pdf`.
- [ ] Click **every link** in the exported PDF as a buyer would. All 9 must open and allow "Make a copy."

✅ *Done when:* one clean PDF exists and every link works.

---

## Step 2 — Mockups (skip if already done) (30–45 min)

Minimum viable set (5 images), brand rules (black / white / off-white, name +
outcome readable in 3s):

- [ ] Cover — "Business Operating System / Turn business chaos into one structured system"
- [ ] Included modules (the 9-item list)
- [ ] Business dashboard preview (KPI Dashboard screenshot)
- [ ] Pipeline / CRM preview (screenshot)
- [ ] "How it works" (the module order 1→8)

✅ *Done when:* 5 PNGs exported, readable on mobile.

---

## Step 3 — Publish on Payhip (30 min) — do this first

- [ ] **Add new product → Digital product.**
- [ ] Name: from `listing-payhip.md` → *Product name*.
- [ ] Upload file: attach `Business-Operating-System-Delivery-Guide.pdf` as the deliverable.
- [ ] Description: paste *Full description* from `listing-payhip.md`.
- [ ] Add the FAQ block from `launch/POLICIES_AND_FAQ.md` (section 3) to the bottom of the description.
- [ ] Price: set **€49** (launch price). Optionally set a "compare at" of €99.
- [ ] Images: upload the 5 mockups; set the cover as the main image.
- [ ] Store policy / refund: paste the refund + license short lines (sections 1–2).
- [ ] **Publish.** Copy the live URL.

✅ *Done when:* the Payhip product page is live and the URL is saved.

---

## Step 4 — Test purchase on Payhip (10 min)

- [ ] Create a 100% discount code (e.g. `TESTONLY`) or use Payhip's preview/test order.
- [ ] Buy the product as a customer.
- [ ] Confirm: order email arrives → download works → PDF opens → a linked Sheet opens and "Make a copy" works.
- [ ] Delete/disable the test code afterwards.

✅ *Done when:* the full buyer flow works end to end.

---

## Step 5 — Publish on Etsy (30–40 min)

- [ ] **Shop Manager → Listings → Add a listing → Digital.**
- [ ] Title: paste from `listing-etsy.md` → *Title*.
- [ ] Photos: upload the 5 mockups (cover first).
- [ ] About: Made by you / A finished product / When made: 2026.
- [ ] Category: Digital Prints / Templates path; Type = Digital download.
- [ ] Price: **€99** (or run an Etsy sale to show the €49 launch price).
- [ ] Quantity: high (e.g. 999). Digital file: upload the delivery-guide PDF.
- [ ] Description: paste *Description* from `listing-etsy.md`, then append the FAQ block (POLICIES_AND_FAQ section 3).
- [ ] Tags: paste all 13 from `listing-etsy.md`.
- [ ] Shop policies: confirm the digital refund + license policy (sections 1–2) is set in Shop → Policies.
- [ ] **Publish.** Copy the live URL.

✅ *Done when:* the Etsy listing is live and the URL is saved.

---

## Step 6 — Record it (5 min)

- [ ] Update `docs/STATUS.md`: mark P-002 **LIVE**, add both URLs, bump "Products live" / "Listings live" to reflect reality.
- [ ] Add sale rows to your revenue tracker as they come in.

---

## Step 7 — First traffic + upsell (20 min)

- [ ] Create 2–3 Pinterest pins from `../../launch/PINTEREST.md` (P-002 titles).
- [ ] Link each pin to the Payhip or Etsy listing.
- [ ] Set up the upsell: offer the **€199 bundle** (Business OS + AI OS + bonus templates) and cross-link P-001 ↔ P-002 in both descriptions.

---

## Done = "LIVE"

P-002 is LIVE when: the listing is published on at least Payhip, a test purchase
succeeded, the buyer can open every file, and the URL is recorded in
`docs/STATUS.md`. With P-001 and P-002 both live, the two-flagship launch is
complete — next expansion products are P-003→P-007 (see `docs/PRODUCT_CATALOG.md`).
