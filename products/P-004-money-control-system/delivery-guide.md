## Page 4 — How to use this product

Always work inside **your own copy**: open a file → **File → Make a copy** → save
to your Drive → edit only your copy. This keeps the originals safe **and your
financial data private**.

**Recommended use:** set up the Budget Tracker first, then log expenses regularly
(a few minutes weekly). The Cashflow Dashboard updates from what you enter.
